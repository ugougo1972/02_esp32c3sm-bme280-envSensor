# 03_電源デザイン(03_POWER_DESIGN)

## 目的

本ファイルは、携帯型環境センサーロガー初号機における電源設計、電源経路、Battery voltage monitor 方針を整理するための資料である。  
初号機では、**電源系の成立優先・安全側実装・分離構成**を基本方針とし、厳密な消費電力最適化は完成後評価とする。

## 電源構成概要

初号機の電源系は以下で構成される。

```
LiPo (3.7V) 
  ↓ JST-PH系コネクタ
TP4056（充電・保護）
  ↓ AWG28配線
AE-TPS63802（昇降圧DC/DC・3.3V出力・EN端子付き）
  ↓ 端子台（4ライン）
メイン基板（XIAO + センサ + RTC + OLED + microSD）
```

## 電源部品仕様

### LiPo（リチウムポリマーバッテリ）

| 項目 | 仕様 |
|------|------|
| 電圧 | 3.7V |
| 容量 | 1000mAh（初期評価用の暫定容量） |
| 接続 | JST-PH系コネクタ（着脱可能） |
| 充電 | TP4056経由 |
| 保護 | TP4056内蔵保護回路に依存 |

### TP4056（充電モジュール）

| 項目 | 仕様 |
|------|------|
| 用途 | LiPo充電・過充電保護 |
| 入力 | USB DC 5V（IN+ / IN-） |
| バッテリ接続 | B+ / B- |
| 出力 | OUT+ / OUT- |
| LED | 充電時赤点灯 |
| 状態 | 到着済み・機能確認済み |

### AE-TPS63802（昇降圧DC/DCコンバータ）

| 項目 | 仕様 |
|------|------|
| 製品 | AE-TPS63802 |
| 入力 | 1P (VIN)：TP4056 OUT+ |
| グラウンド | 2P (GND)：GNDバス |
| 出力 | 3P (VOUT)：3.3V（安定化） |
| EN制御 | 4P (EN)：HIGH=動作 / LOW=シャットダウン |
| 用途 | 3.3V電源生成・Deep Sleep時電源遮断 |
| 状態 | 到着済み・実装中（ハンダ付け停滞中） |

### コンデンサ構成

| 部品 | 容量 | 種別 | 接続 | 目的 |
|------|------|------|------|------|
| C1 | 0.1µF | MLCC | TP4056 OUT+ ↔ OUT- | 入力平滑化 |
| C2 | 47µF | 電解（長足→VOUT） | TPS63802 VOUT ↔ GND | 出力平滑化 |
| C3 | 0.1µF | MLCC | TPS63802 VOUT ↔ GND | 出力高周波ノイズ除去 |
| C4 | 0.1µF | MLCC（オプション） | ADC入力 ↔ GND | ADC安定化（必要時）|

### 配線仕様

| 区間 | 線材 | 備考 |
|------|------|------|
| JST ↔ TP4056 B+/B- | AWG24 | 大電流対応 |
| TP4056 OUT ↔ TPS63802 I | AWG28 | 標準配線 |
| TPS63802 O ↔ 3.3Vライン | AWG28 | 標準配線 |
| GND連続配線 | スズメッキ線 | 低インピーダンス |
| 3.3Vライン | スズメッキ線 | 低インピーダンス |

## 端子台インターフェース（4ライン）

### 端子台ライン構成

電源基板からメイン基板へ、端子台を経由して4本のラインで接続する。

| ライン | 信号 | 接続元 | 接続先 | 目的 |
|--------|------|--------|--------|------|
| 1 | 3.3V | AE-TPS63802 3P | メイン基板3.3V | センサ・RTC・OLED・microSD給電 |
| 2 | GND | GNDバス | メイン基板GND | 共通GND |
| 3 | VBAT_RAW | TP4056 OUT+ | 分圧回路（メイン基板側） | Battery voltage monitor測定用 |
| 4 | EN | AE-TPS63802 4P | XIAO GPIO（未確定） | Deep Sleep時電源遮断制御 |

## Battery Voltage Monitor 設計

### 目的

LiPo の電圧低下を MCU で監視し、OLED 電池アイコン表示や低電圧警告へつなげる。

### 分圧回路（メイン基板側に実装）

```text
VBAT_RAW (TP4056 OUT+) ----[R1:100kΩ]----+---- ADC入力候補
                                          |
                                        [R2:100kΩ]
                                          |
GND (共通) --------------------------------+---- XIAO GND
```

### 分圧回路設計値

| 項目 | 仕様 | 備考 |
|------|------|------|
| R1 / R2 | 100kΩ × 2（1206 / 1%） | 1:1分圧 |
| 分圧比 | 1:2 | VBAT_RAW → 約1.85V（満充電時） |
| ADC入力 | XIAO GPIO10候補 | 未確定・保留中 |
| ADC安定化 | 0.1µF MLCC（オプション） | ふらつき確認後に追加判断 |

### 分圧回路の注意事項

- 測定対象は **TP4056 OUT+ / OUT-** とする（LiPo端子ではなく）
- 分圧回路は **メイン基板側** に実装する（電源基板ではなく）
- TP4056 OUT+ を ADC に直接接続してはいけない（分圧必須）
- ADCピンの最終確定は後段で行う
- 実装後、テスター実測値と ADC読値を比較して補正を確認する

## EN端子（Power Enable）の活用方針

### 目的

Deep Sleep 中に AE-TPS63802 をシャットダウンさせることで、  
センサ・OLED・その他3.3V機器への電力供給を完全に遮断する。

### EN制御の方式

| 状態 | EN電位 | 3.3V出力 | 用途 |
|------|--------|----------|------|
| 通常動作 | HIGH | ON（3.3V） | 測定・保存・表示 |
| Deep Sleep | LOW | OFF（≈0V） | 消費電力最小化 |

### 制御対象GPIO（未確定）

- 現在：未確定・保留中
- 候補：XIAO GPIO（未割り当てGPIOから選定予定）
- 確定予定時期：分圧回路実装時

### 実装上の注意

- EN端子は HIGH/LOW の2値制御のみ
- 類似デバイスでは、EN→GND でシャットダウン（今回も同様予定）
- 実装時に実際の制御電位を確認する

## 注意事項

### 電源接続時

- LiPo 極性を確認してから接続する
- 3.3V 出力を単体で確認してから MCU に接続する
- GND は全デバイスで共通とする
- 短絡を絶対に避ける

### TP4056 運用時

- OUT± は本実装ではヘッダーピン着脱点にしない（固定配線）
- USB抜き差し荷重は最終的に筐体側でも受ける前提
- 充電中の異常発熱・異臭を監視する

### AE-TPS63802 運用時

- 正規配線：1P(VIN) / 2P(GND) / 3P(VOUT) / 4P(EN)
- EN制御時にMCUのGPIOレベル（3.3V）で制御可能か確認する
- シャットダウン時に3.3V系デバイスの動作が完全に停止することを確認する

### 電力ライン設計

- 電源ラインは信号線より優先して整理する
- 高電流区間は太い配線またはスズメッキ線を使用する
- ノイズが懸念される場合はコンデンサを追加検討する
