# 05_WIRING_DIAGRAM

## 目的

本ファイルは、携帯型環境センサーロガー初号機における配線方針と、各モジュール間の接続関係を整理するためのものである。  
本段階では CAD による正式回路図ではなく、**配線単位の接続表**として整理し、ユニバーサル基板実装時の基準資料とする。

## 本ファイルの前提

- 最終構成候補MCUは **Seeed Studio XIAO ESP32S3 Plus**
- 初号機は **ユニバーサル基板 + 既製モジュール実装** を前提とする
- **USB通信用USB** と **LiPo充電用USB** は分離する
- センサ系・表示系・記録系・UI系は、現時点で **USB給電ベースの統合動作実績あり**
- **LiPo → TP4056 → XC9306 → XIAO** の最小電源経路は成立済み
- TP4056系については、**充電電流値・保護回路有無・負荷共有可否は未確認**
- 3.3V電源系は **XC9306系昇降圧DC/DC を第一候補** とする
- 電流測定は完成まで実施しない
- 初号機では **電源基板** と **メイン基板** を分離する

## 全体配線構成

初号機の配線は、以下の5系統に分けて整理する。

1. 電源基板
2. メイン基板電源入力
3. I2Cバス
4. SPI（microSD）
5. GPIO入力 / LED出力（RGBエンコーダ）

## 1. 電源基板配線

### 電源基板の役割

- LiPo 接続
- LiPo 充電
- 3.3V 生成
- メイン基板への 3.3V / GND / VBAT_SENSE_RAW 出力

### 電源基板接続表

| 項番 | 接続元 | 接続先 | 状況 | 備考 |
|------|--------|--------|------|------|
| P-1 | LiPo + | TP4056 B+ | 成立済み | JST経由を想定 |
| P-2 | LiPo - | TP4056 B- | 成立済み | JST経由を想定 |
| P-3 | USB充電 + | TP4056 IN+ | 成立済み | 充電用USB |
| P-4 | USB充電 - | TP4056 IN- | 成立済み | 充電用USB GND |
| P-5 | TP4056 OUT+ | XC9306 I | 成立済み | 負荷側出力 |
| P-6 | TP4056 OUT- | XC9306 G | 成立済み | 共通GND |
| P-7 | XC9306 O | 3.3V端子台 | 成立済み | メイン基板へ |
| P-8 | TP4056 OUT- | GND端子台 | 成立済み | メイン基板へ |
| P-9 | TP4056 OUT+ | VBAT_SENSE_RAW端子台 | 方針確定 | 分圧回路用 |

### 電源基板の固定方針

- TP4056 OUT± は本実装でヘッダーピン着脱点にしない
- TP4056 は面固定 + 配線の引っ張り止めを行う
- USB抜き差し荷重は最終的に筐体側でも受ける

## 2. メイン基板電源入力

### 電源基板 → メイン基板

| 項番 | 信号 | 接続先 | 状況 | 備考 |
|------|------|--------|------|------|
| M-P1 | 3.3V | XIAO 3V3 | 成立済み | 外部3.3V入力 |
| M-P2 | GND | XIAO GND | 成立済み | GND共通 |
| M-P3 | 3.3V | 各モジュール VCC | 方針確定 | BME280 / LTR390 / OLED / DS3231 / microSD |
| M-P4 | GND | 各モジュール GND | 方針確定 | GND共通 |
| M-P5 | VBAT_SENSE_RAW | 分圧回路 R1上端 | 方針確定 | battery monitor 用 |

## 3. Battery voltage monitor 配線

### 分圧回路基本配線

```text
TP4056 OUT+ (VBAT_SENSE_RAW) ---- R1(100kΩ) ----+---- ADC入力候補
                                                |
                                              R2(100kΩ)
                                                |
TP4056 OUT- / GND ------------------------------+---- XIAO GND
```

### 分圧回路接続表

| 項番 | 接続元 | 接続先 | 状況 | 備考 |
|------|--------|--------|------|------|
| B-1 | VBAT_SENSE_RAW | R1上端 | 方針確定 | TP4056 OUT+ |
| B-2 | R1下端 / R2上端 | ADC入力候補 | 未実装 | GPIO10は保留 |
| B-3 | R2下端 | GND | 方針確定 | XIAO GND と共通 |
| B-4 | ADC入力点 | 0.1uF → GND | 任意 | 値が揺れる場合のみ追加 |

### Battery voltage monitor に関する注意

- 測定対象は **TP4056 OUT+ / OUT-** とする
- 分圧回路は **メイン基板側** に実装する
- ADC入力候補GPIOは現時点で最終未確定
- `TP4056 OUT+` を ADC に直接入れない

## 5. SPI（microSD）配線

microSDモジュールは SPI 接続とする。

### SPI配線表

| 項番 | XIAO端子 | GPIO | microSD | 状況 | 備考 |
|------|----------|------|---------|------|------|
| S-1 | D2 | GPIO3 | CS | 成立済み | Chip Select |
| S-2 | D8 | GPIO7 | SCK | 成立済み | SPI Clock |
| S-3 | D9 | GPIO8 | MISO | 成立済み | SPI MISO |
| S-4 | D10 | GPIO9 | MOSI | 成立済み | SPI MOSI |
| S-5 | 3.3V | - | VCC | USB給電で成立済み | 電源 |
| S-6 | GND | - | GND | 成立済み | GND |

### microSD運用上の注意

- `SD.begin failed` 対策として、必要に応じて以下を用いる  
  - CS High
  - `SPI.begin(...)`
  - `SD.begin(CS, SPI, 1000000)`
- 3V3表記モジュールは 3.3V 給電で扱う
- SPI配線はできるだけ短くする
- LiPo系 + microSD の長時間評価は後段で確認する

## 6. RGB LED付きロータリーエンコーダ配線

RGB LED付きスイッチ付きロータリーエンコーダを UI 入力として使用する。

### Encoder配線表

| 項番 | XIAO端子 | GPIO | Encoder | 状況 | 備考 |
|------|----------|------|---------|------|------|
| E-1 | D0 | GPIO1 | A | 成立済み | 回転入力 |
| E-2 | D1 | GPIO2 | B | 成立済み | 回転入力 |
| E-3 | D3 | GPIO4 | SW | 成立済み | 押し込み入力 |
| E-4 | D11 | GPIO38 | LED R | 成立済み | 電流制限抵抗を介す |
| E-5 | D12 | GPIO39 | LED G | 成立済み | 電流制限抵抗を介す |
| E-6 | D13 | GPIO40 | LED B | 成立済み | 電流制限抵抗を介す |
| E-7 | GND または 3.3V | - | 共通端子 | [CHECK] | LED極性確認継続 |

### UI実装上の注意

- 回転検出は ESP32Encoder + PCNT方式を採用する
- 右回転 = CW、左回転 = CCW
- 5ノッチ = 5イベント成立済み
- PUSH / RELEASE 成立済み

## 配線上の注意事項

### 1. GNDは必ず共通にする

以下はすべて **GND共通** とする。

- XIAO
- BME280
- LTR390
- OLED
- DS3231
- microSD
- RGBエンコーダ
- 分圧回路
- XC9306
- TP4056
- LiPo

### 2. I2Cはバス配線とする

- SDA は全デバイス共通
- SCL は全デバイス共通

できるだけバス配線に近い形で配線し、不要に長い引き回しを避ける。

### 3. SPI配線は短くする

以下はできるだけ短く配線する。

- SCK
- MOSI
- MISO
- CS

### 4. 電源ラインは他信号線より優先して整理する

以下の系統は、信号線より先にレイアウト検討する。

- LiPo → TP4056
- TP4056 → XC9306
- XC9306 → 3.3Vライン
- 3.3Vライン → XIAO / センサ / OLED / microSD
- VBAT_SENSE_RAW → 分圧回路

### 5. 電池系の確認順

以下の順で確認する。

1. LiPo 単体確認
2. TP4056系確認
3. XC9306系確認
4. XIAO 単体給電確認
5. LiPo駆動で Blink 確認
6. battery voltage monitor 実装
7. I2C / SPI / Deep Sleep 再統合確認
