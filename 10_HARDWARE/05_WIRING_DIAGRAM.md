### microSD運用上の注意（GPIO44 CS確定版）✅

- `SD.begin failed` 対策として、以下の手順を使用する  
  - **D7(GPIO44) を OUTPUT に設定**✅
  - **D7(GPIO44) を HIGH に設定**✅
  - `SPI.begin(...)`
  - `SD.begin(44, SPI, 1000000)` を試す
- 3V3表記モジュールは 3.3V 給電で扱う
- SPI配線はできるだけ短くする（SCK / MOSI / MISO / CS）
- LiPo系 + microSD の長時間安定性は後段で確認する

### DeepSleep対応処理（必須・確定版）✅

```cpp
// Deep Sleep移行前
pinMode(PIN_SPI_CS, OUTPUT);      // D7(GPIO44)
digitalWrite(PIN_SPI_CS, HIGH);   // CS=HIGH固定
SPI.end();                          // SPI終了
```

### GPIO44(SPI_CS)使用上の注意

- **GPIO44はUART RX兼用**だが、初号機は **USB CDC主体** のためGPIO利用可
- **UARTデバッグ不可**（USB CDC経由でのデバッグに限定）

### TPS63802_EN制御配線

```text
3.3Vバス --[R_EN:100kΩ]--+--- XIAO D6(GPIO43) ---+--- 4ライン端子台ライン4 ---[AE-TPS63802 4P(EN)]
                          |                       |
                          +-(プルアップ・Hi-Z対策)-+
```

### EN制御配線表（確定版）✅

| 項番 | 接続元 | 接続先 | 値 | メイン基板座標 | 状況 |
|------|--------|--------|------|--------------|------|
| EN-1 | 3.3Vバス（座標(11,01)） | R_EN(100kΩ)入力 | 100kΩ | **(11,01)→(11,08)** ✅ | 🔄 実装中 |
| EN-2 | R_EN(100kΩ)出力 | XIAO D6(GPIO43)合流 | - | **(14,08)** ✅ | 🔄 実装中 |
| EN-3 | XIAO D6(GPIO43) | 端子台ライン4 | - | (34,25) | 🔄 実装中 |

### R_EN(100kΩ)プルアップ配置（確定版）✅

- **配置座標：(12,08)～(14,08)**✅
- **入力経路：(11,01)→(11,08)→3.3Vバス**✅
- **出力：(14,08)→D6/GPIO43合流**✅

### GPIO43使用上の注意

- **GPIO43はRTC GPIO非対応**のため、DeepSleep中にHi-Z化する可能性あり
- **R_EN(100kΩ)プルアップでHi-Z時もEN端子をHIGH維持**✅
- スケッチ側の追加対策不要

### DeepSleep制御フロー

1. 通常動作時：D6(GPIO43)=HIGH → AE-TPS63802有効・3.3V出力
2. DeepSleep直前：microSD CS=HIGH・SPI.end()実施
3. DeepSleep移行：D6(GPIO43)=LOW → AE-TPS63802無効・3.3V遮断
4. DeepSleep中：R_EN(100kΩ)プルアップによりGPIO43 Hi-Z化対策
5. 復帰時：D6(GPIO43)=HIGH復帰 → 3.3V出力再開

## 配線上の基本ルール

### 1. GNDは必ず共通にする

以下はすべて **GND共通** とする。

- XIAO
- BME280
- LTR390
- OLED
- DS3231
- microSD
- **MCP23017**✅
- RGBエンコーダ
- 分圧回路
- AE-TPS63802
- TP4056
- LiPo

### 2. I2Cはバス配線とする

- SDA は全デバイス共通（**5機器対応**：BME280/LTR390/OLED/DS3231/MCP23017）✅
- SCL は全デバイス共通

できるだけバス配線に近い形で配線し、不要に長い引き回しを避ける。

### 3. SPI配線は短くする

以下はできるだけ短く配線する。

- SCK（D8/GPIO7）
- MOSI（D10/GPIO9）
- MISO（D9/GPIO8）
- **CS（D7/GPIO44）**✅ **確定**

### 4. 電源ラインは他信号線より優先して整理する

以下の系統は、信号線より先にレイアウト検討する。

- LiPo → TP4056
- TP4056 → AE-TPS63802
- AE-TPS63802 → 3.3Vライン
- 3.3Vライン → XIAO / センサ / OLED / microSD / **MCP23017**✅
- VBAT_SENSE_RAW → 分圧回路 → **D3(GPIO4)**✅
- **EN → R_EN(100kΩ) → D6(GPIO43)**✅

### 5. 電池系の確認順

以下の順で段階的に確認する。

1. ✅ LiPo 単体確認
2. ✅ TP4056系確認
3. ✅ AE-TPS63802系確認
4. ✅ XIAO 単体給電確認
5. ✅ LiPo駆動で Blink 確認
6. 🔄 **メイン基板実装（分圧回路・R_EN・MCP23017）**
7. 🔄 **Battery voltage monitor実装・確認（D3/GPIO4）**
8. 🔄 **EN制御確認（D6/GPIO43）**
