# 05_WIRING_DIAGRAM

## 目的

本ファイルは、携帯型環境センサーロガー初号機における配線方針と、各モジュール間の接続関係を整理するためのものである。  
本段階では CAD による正式回路図ではなく、**配線単位の接続表**として整理し、ユニバーサル基板実装時の基準資料とする。

## 本ファイルの前提

- 最終構成候補MCUは **Seeed Studio XIAO ESP32S3 Plus**
- 初号機は **ユニバーサル基板 + 既製モジュール実装** を前提とする
- **USB通信用USB** と **LiPo充電用USB** は分離する
- センサ系・表示系・記録系・UI系は、現時点で **USB給電ベースの統合動作実績あり**
- **LiPo → TP4056 → AE-TPS63802 → XIAO** の最小電源経路は成立済み
- AE-TPS63802については、**通電試験・EN制御確認は後段**
- 3.3V電源系は **AE-TPS63802 昇降圧DC/DC（EN端子付き）を採用** とする
- 電流測定は完成まで実施しない
- 初号機では **電源基板** と **メイン基板** を分離する

## 全体配線構成

初号機の配線は、以下の6系統に分けて整理する。

1. 電源基板
2. メイン基板電源入力（4ライン端子台経由）
3. I2Cバス
4. SPI（microSD）
5. GPIO入力 / LED出力（RGBエンコーダ）
6. Battery voltage monitor（分圧回路）

## 3. Battery Voltage Monitor 配線（メイン基板側実装）

### 分圧回路基本配線

```text
VBAT_SENSE_RAW (TP4056 OUT+) ----[R1:100kΩ]----+---- ADC入力候補(GPIO10)
                                               |
                                             [R2:100kΩ]
                                               |
GND (XIAO GND) --------------------------------+---- XIAO GND
```

### 分圧回路仕様

| 項目 | 仕様 |
|------|------|
| R1 / R2 | 100kΩ × 2（1206 / 1%） |
| 分圧比 | 1:2（R1+R2 : R2） |
| 満充電時 ADC入力 | 約1.85V（3.7V × 0.5） |
| 安全性 | ADC入力 < 3.3V で安全 |
| 安定化コンデンサ | 0.1µF MLCC（オプション・ふらつき確認後） |

### 分圧回路接続表

| 項番 | 接続元 | 接続先 | 容量/値 | 状況 | 備考 |
|------|--------|--------|---------|------|------|
| B-1 | VBAT_SENSE_RAW（端子台ライン3） | R1上端 | 100kΩ | ⬜ 待機中 | TP4056 OUT+ |
| B-2 | R1下端 / R2上端 | ADC入力候補 | - | ⬜ 待機中 | GPIO10は現時点で予約 |
| B-3 | R2下端 | GND（メイン基板GND） | - | ⬜ 待機中 | XIAO GND共通 |
| B-4 | ADC入力点 | 0.1µF → GND | 0.1µF | ⬜ 任意 | ふらつき確認後判断 |

### Battery voltage monitor に関する注意

- 測定対象は **TP4056 OUT+ / OUT-** とする（LiPo端子ではなく）
- 分圧回路は **メイン基板側** に実装する（電源基板ではなく）
- ADC入力候補GPIO は現時点で最終未確定（GPIO10予約）
- `TP4056 OUT+` を ADC に直接入れない（分圧必須）
- ADC中点の電圧は **必ず GND 経由で計測** する

### I2C配線表

| 項番 | XIAO端子 | GPIO | 接続先 | 状況 | 備考 |
|------|----------|------|--------|------|------|

| I-3 | 3.3V | - | BME280 / LTR390 / SSD1306 / DS3231 VCC | 🔄 待機中 | 端子台ライン1経由 |

### I2C認識状況

| 機器 | I2Cアドレス | 確認状況 |
|------|----------|----------|
| BME280 | 0x76 | ✅ 確認済み |
| LTR390 | 0x53 | ✅ 確認済み |
| OLED SSD1306 | 0x3C | ✅ 確認済み |
| DS3231 | 0x68 | ✅ 確認済み |
| AT24C32 | 0x57 | ✅ 確認済み |

### I2C配線上の注意

- SDA / SCL は全デバイスで共通バス（複数接続OK）
- できるだけバス配線に近い形で配線する
- 不要に長い引き回しを避ける
- プルアップ抵抗はモジュール側に搭載済みの前提

### SPI接続対象

### SPI配線表

| 項番 | XIAO端子 | GPIO | microSD信号 | 状況 | 備考 |
|------|----------|------|----------|------|------|
| S-1 | D2 | GPIO3 | CS | ✅ 成立済み | Chip Select |
| S-2 | D8 | GPIO7 | SCK | ✅ 成立済み | SPI Clock |
| S-3 | D9 | GPIO8 | MISO | ✅ 成立済み | SPI MISO |
| S-4 | D10 | GPIO9 | MOSI | ✅ 成立済み | SPI MOSI |
| S-5 | 3.3V | - | VCC | 🔄 待機中 | 端子台ライン1経由 |
| S-6 | GND | - | GND | 🔄 待機中 | 端子台ライン2経由 |

### microSD運用上の注意

- `SD.begin failed` 対策として、以下の手順を使用する  
  - GPIO3 を OUTPUT に設定
  - GPIO3 を HIGH に設定
  - `SPI.begin(...)`
  - `SD.begin(3, SPI, 1000000)` を試す
- 3V3表記モジュールは 3.3V 給電で扱う
- SPI配線はできるだけ短くする（SCK / MOSI / MISO / CS）
- LiPo系 + microSD の長時間安定性は後段で確認する

| E-2 | D1 | GPIO2 | B | ✅ 成立済み | 回転入力（CW/CCW検出） |
| E-3 | D3 | GPIO4 | SW | ✅ 成立済み | 押し込み入力 |

- 右回転 = CW、左回転 = CCW

- PUSH / RELEASE を安定検出（実績確認済み）
- RGB LED は各色に外付け電流制限抵抗を入れる

## 配線上の基本ルール

### 1. GNDは必ず共通にする

以下はすべて **GND共通** とする。

- XIAO
- BME280
- LTR390
- OLED
- DS3231
- microSD
- RGBエンコーダ
- 分圧回路
- AE-TPS63802
- TP4056
- LiPo

### 2. I2Cはバス配線とする

- SDA は全デバイス共通
- SCL は全デバイス共通

できるだけバス配線に近い形で配線し、不要に長い引き回しを避ける。

### 3. SPI配線は短くする

以下はできるだけ短く配線する。

- SCK
- MOSI
- MISO
- CS

### 4. 電源ラインは他信号線より優先して整理する

以下の系統は、信号線より先にレイアウト検討する。

- LiPo → TP4056
- TP4056 → AE-TPS63802
- AE-TPS63802 → 3.3Vライン
- 3.3Vライン → XIAO / センサ / OLED / microSD
- VBAT_SENSE_RAW → 分圧回路

### 5. 電池系の確認順

以下の順で段階的に確認する。

1. LiPo 単体確認
2. TP4056系確認
3. AE-TPS63802系確認
4. XIAO 単体給電確認
5. LiPo駆動で Blink 確認
6. Battery voltage monitor 実装
7. I2C / SPI / Deep Sleep 再統合確認
