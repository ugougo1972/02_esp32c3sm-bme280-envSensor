# 02_パーツリスト

本ファイルは、現行構成で使用する部品の一覧を管理するための文書です。  
採用理由、変更履歴、試験結果、実装進捗は本ファイルに記載しません。

## 1. 文書責務

| 項目 | 扱い |
|---|---|
| 現行部品一覧 | 記載する |
| 型番・仕様 | 記載する |
| 数量 | 判明している範囲で記載する |
| 到着状況 | 必要最小限のみ記載する |

| 旧部品・廃止部品 | `90_HISTORY/` に分離 |

| 実装進捗 | `10_HARDWARE/07_HARDWARE_STATUS.md` に分離 |
