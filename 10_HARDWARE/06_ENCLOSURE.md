# 06_ENCLOSURE

## 目的

本ファイルは、携帯型環境センサーロガー初号機の筐体（エンクロージャ）設計方針を整理するためのものである。  
初号機では完成度よりも **評価・改造・再配線のしやすさを優先** し、量産前提ではなく試作機前提の筐体とする。

## 初号機筐体の基本方針

初号機の筐体は以下の方針で設計する。

| 項番 | 方針 | 内容 |
|------|------|------|
| E-1 | 試作優先 | 分解・再配線・部品交換が容易な構造 |
| E-2 | 汎用ケース使用 | 既製品ケースを加工して使用 |
| E-3 | ネジ止め構造 | 接着固定は行わない |
| E-4 | 基板固定 | ユニバーサル基板をスペーサで固定 |
| E-5 | センサ開口 | 温湿度・気圧・照度・UV用に開口を設ける |
| E-6 | 充電口分離 | USB（通信）とUSB（充電）は別位置に配置 |
| E-7 | 電池交換可能 | LiPo電池は交換可能構造 |
| E-8 | 将来作り直し前提 | 初号機は「ケース設計評価機」と位置付ける |
| E-9 | 二基板構成 | メイン基板と電源基板を分離して配置する |
| E-10 | 電源基板着脱性 | 電源基板とメイン基板を端子台でケーブル接続・着脱可能 |

## ケース選定方針

ケースは以下の条件で選定する。

| 項番 | 条件 | 理由 |
|------|------|------|
| K-1 | ABS または ポリカーボネート | 加工しやすい |
| K-2 | ネジ止めタイプ | 分解可能 |
| K-3 | 基板固定用ボスあり | スペーサ固定可能 |
| K-4 | 外形 100mm 以下 | 携帯性確保 |
| K-5 | 厚さ 30mm 以下 | 携帯性確保 |
| K-6 | フタ加工可能 | OLED窓・Encoder穴加工 |
| K-7 | 側面加工可能 | USB・SDスロット開口 |
| K-8 | 二基板配置余地あり | メイン基板と電源基板を分離配置できる |
| K-9 | 端子台用開口 | メイン基板 ← → 電源基板接続ケーブル |

## 開口部設計方針

### 1. OLED表示窓

| 項目 | 内容 |
|------|------|
| 位置 | 上面 |
| 内容 | OLED表示窓 |
| サイズ | 128×64px相当（実寸側辺+余白） |
| 固定 | 内側からスペーサ固定 |
| 保護 | アクリル板で保護検討 |

### 2. Rotary Encoder

| 項目 | 内容 |
|------|------|
| 位置 | 上面 または側面 |
| 穴タイプ | 丸穴（軸径対応） |
| 固定 | ナット固定 |
| 機能 | 回転 + 押し込み |
| LED | RGB LED用隙間確保 |

### 3. センサ開口

| センサ | 開口方法 | 必須度 | 注意 |
|--------|----------|--------|------|
| BME280 | 通気穴（複数） | 必須 | ケース内密閉禁止・気圧測定精度確保 |
| LTR390 | 透明窓 | 必須 | UV/可視光透過必要・直射日光対策 |
| DS3231 | 開口不要 | - | 温度影響少 |

### 4. USB（2種類）

| USB種類 | 用途 | 位置 | 注意 |
|--------|------|------|------|
| USB（MCU） | 書込み・シリアル通信 | メイン基板側面 | XIAO直近 |
| USB（TP4056） | LiPo充電 | 電源基板側面 | 充電専用・通信分離 |

### 5. microSD スロット

| 項目 | 内容 |
|------|------|
| 位置 | メイン基板側面 |
| 機能 | カード抜き差し可能 |
| 保護 | スライダー式カバー検討 |

### 6. 端子台接続開口（メイン基板 ← → 電源基板）

| 項目 | 内容 |
|------|------|
| 位置 | メイン基板側面（下部） |
| サイズ | 端子台（4ライン）引き出し用開口 |
| ケーブル | 短いケーブル（3〜10cm）で接続予定 |

## 内部配置方針

ユニバーサル基板上の配置方針と、筐体内配置方針を一致させる。

### メイン基板配置

| 位置 | 部品 | 高さ目安 | 備考 |
|------|------|----------|------|
| 上部 | OLED | 最高 | 表示窓面が上を向く |
| 上部側面 | Rotary Encoder | 最高 | 回転軸がケース上面へ突き出す |
| 中央 | XIAO ESP32S3 Plus | 中 | 配線中心 |
| 左側 | BME280 / LTR390 / DS3231 | 低～中 | I2C系を近接配置・通気確保 |
| 右側 | microSD | 中 | SPI配線短縮 |
| 下部 | 分圧回路（R1/R2） | 低 | Battery voltage monitor用 |

### 電源基板配置

| 位置 | 部品 | 高さ目安 | 備考 |
|------|------|----------|------|
| 内部下部 | TP4056 | 低 | 充電USB開口へ向ける |
| 内部下部 | AE-TPS63802 | 低～中 | 出力安定化優先 |
| 内部 | コンデンサ（C1/C2/C3） | 低 | TP4056・TPS63802 周辺 |
| 下部 | 端子台（4ライン） | 低 | メイン基板との接続点 |

### 基板間接続方針

| 項目 | 内容 |
|------|------|
| 接続方式 | 4ライン端子台 + 短いケーブル（AWG28） |
| ケーブル長 | 3～10cm（ケース内配線に応じて調整） |
| スペース | メイン基板・電源基板間に隙間確保（再配線性向上） |
| 着脱性 | 端子台でケーブル着脱可能 |

### LiPo電池配置

| 位置 | 内容 |
|------|------|
| ケース下部 | 両面テープ + スポンジで固定 |
| 保護 | 発熱部品（TP4056等）との間隔確保 |
| 交換性 | JSTコネクタで着脱可能 |

### USB・SDスロット側面配置

| 側面 | デバイス | 優先度 |
|------|----------|--------|
| メイン側面（上） | microSD スロット | 高 |
| メイン側面（中） | USB（MCU・通信用） | 高 |
| 電源側面（下） | USB（TP4056・充電用） | 高 |
| 側面（下部） | 端子台接続ケーブル | 中 |

## TP4056 固定方針

| 項目 | 方針 |
|------|------|
| 主固定 | 絶縁両面テープで面固定 |
| 補助固定 | 配線保持または結束で引っ張り止め |
| USB荷重 | 筐体開口でも受ける（ケース側面サポート） |
| OUT± | 着脱点にしない（配線固定） |

### 注意事項

- TP4056 は固定穴がないため、配線のみで宙吊りにしない
- 両面テープのみで荷重を受け切る前提にしない
- OUT± や JST 部に抜き差し力を集中させない
- USB コネクタはケース側面で補強する

---

## AE-TPS63802 固定方針

| 項目 | 方針 |
|------|------|
| 主固定 | 絶縁両面テープで面固定 |
| 補助固定 | 配線保持または結束で引っ張り止め |
| 出力安定化 | 大きなコンデンサ（C2: 47µF）を近接配置 |
| EN端子 | メイン基板へのGPIO制御ケーブル |

### 注意事項

- TPS63802 も固定穴がないため、配線のみで宙吊りにしない
- 入出力端子に抜き差し力を集中させない
- 熱放散を考慮した配置が望ましい（実装初期は熱計測なし） |

---

## LiPo電池配置方針

| 項目 | 方針 |
|------|------|
| 固定方法 | 両面テープ + スポンジ（振動吸収） |
| 交換方式 | JSTコネクタ接続（着脱可能） |
| 保護 | 金属フレーム・部品との絶縁 |
| 配置 | ケース下部・発熱部品から離す |
| 温度管理 | 初号機は温度計測なし（完成後評価） |

## 初号機筐体の役割

初号機筐体は以下を目的とする。

| 項番 | 評価項目 | 優先度 | 備考 |
|------|----------|--------|------|
| T-1 | サイズ感 | 高 | 携帯性確保 |
| T-2 | 操作性（Encoder回転） | 高 | 回転検出の易さ |
| T-3 | OLED視認性 | 高 | 表示窓位置・反射防止 |
| T-4 | USB位置の分離 | 高 | 通信USBと充電USBの独立性 |
| T-5 | microSD交換性 | 高 | カード着脱の容易さ |
| T-6 | 電池交換性 | 高 | LiPo着脱・容量変更対応 |
| T-7 | センサ値のケース影響 | 中 | 気圧・照度・温度測定精度 |
| T-8 | 発熱管理 | 中 | Long Run での温度確認 |
| T-9 | ノイズ対策 | 低 | 初号機では後段 |
| T-10 | 配線のしやすさ | 高 | 再配線・試験のしやすさ |
| T-11 | 電源基板とメイン基板の整備性 | 高 | 着脱・修理・追加実装 |

## 初号機筐体の最終設計方針（実装前の確定事項）

### 基本方向

- ケース内にメイン基板と電源基板を独立して配置
- 端子台 + ケーブルで接続（分離可能）
- 通信用USB（XIAO）と充電用USB（TP4056）をケース異なる側面に配置
- LiPo電池はJSTコネクタで着脱可能
- 初号機は「設計評価機」として、将来の分解・再製造前提

### 外部開口の確定順序

1. **必須開口**（デバイス着脱）
   - microSD スロット
   - USB（通信・充電）×2
   - 端子台接続ケーブル通路

2. **センサ開口**（測定精度確保）
   - BME280 通気穴
   - LTR390 透明窓
   - Encoder 丸穴

3. **表示開口**（UI確認）
   - OLED 表示窓

### 筐体選定の進め方（後段）

1. メイン基板・電源基板のサイズを確認（各72mm×47mm）
2. 二基板を縦置き/横置きで配置試験
3. 開口位置・サイズの図面化
4. 既製品ケース（100mm×60mm×35mm程度）の候補選定
5. 加工試験（穴あけ・スリット）
6. 組立試験（基板固定・配線・着脱確認）
