# 06_ENCLOSURE

## 目的

本ファイルは、携帯型環境センサーロガー初号機の筐体（エンクロージャ）設計方針を整理するためのものである。  
初号機では完成度よりも **評価・改造・再配線のしやすさを優先** し、量産前提ではなく試作機前提の筐体とする。

---

## 初号機筐体の基本方針

初号機の筐体は以下の方針で設計する。

| 項番 | 方針 | 内容 |
|------|------|------|
| E-1 | 試作優先 | 分解・再配線・部品交換が容易な構造 |
| E-2 | 汎用ケース使用 | 既製品ケースを加工して使用 |
| E-3 | ネジ止め構造 | 接着固定は行わない |
| E-4 | 基板固定 | ユニバーサル基板をスペーサで固定 |
| E-5 | センサ開口 | 温湿度・気圧・照度・UV用に開口を設ける |
| E-6 | 充電口分離 | USB（通信）とUSB（充電）は別位置に配置 |
| E-7 | 電池交換可能 | LiPo電池は交換可能構造 |
| E-8 | 将来作り直し前提 | 初号機は「ケース設計評価機」と位置付ける |
| E-9 | 二基板構成 | メイン基板と電源基板を分離して配置する |
| E-10 | 電源基板着脱性 | 電源基板とメイン基板を端子台でケーブル接続・着脱可能 |
| **E-11** | **GPIO割当確定** | **全GPIO割り当て確定版・メイン基板レイアウト確定版を反映** |
| **E-12** | **DeepSleep対応** | **R_EN(100kΩ)・GPIO43・microSD CS処理確定** |

## ケース選定方針

ケースは以下の条件で選定する。

| 項番 | 条件 | 理由 |
|------|------|------|
| K-1 | ABS または ポリカーボネート | 加工しやすい |
| K-2 | ネジ止めタイプ | 分解可能 |
| K-3 | 基板固定用ボスあり | スペーサ固定可能 |
| K-4 | 外形 120mm 以下 | 携帯性確保（メイン基板95mm × 2基板考慮） |
| K-5 | 厚さ 40mm 以下 | 携帯性確保（二基板配置・ケーブル考慮） |
| K-6 | フタ加工可能 | OLED窓・Encoder穴加工 |
| K-7 | 側面加工可能 | USB・SDスロット開口 |
| K-8 | 二基板配置余地あり | メイン基板(95×72) + 電源基板(72×47)を分離配置できる |
| K-9 | 端子台用開口 | メイン基板 ← → 電源基板接続ケーブル |

## TP4056 固定方針

| 項目 | 方針 |
|------|------|
| 主固定 | 絶縁両面テープで面固定 |
| 補助固定 | 配線保持または結束で引っ張り止め |
| USB荷重 | 筐体開口でも受ける（ケース側面サポート） |
| OUT± | 着脱点にしない（配線固定） |

### 注意事項

- TP4056は固定穴がないため、配線のみで宙吊りにしない
- 両面テープのみで荷重を受け切る前提にしない
- OUT± や JST 部に抜き差し力を集中させない
- USB コネクタはケース側面で補強する

---

## AE-TPS63802 固定方針

| 項目 | 方針 |
|------|------|
| 主固定 | 絶縁両面テープで面固定 |
| 補助固定 | 配線保持または結束で引っ張り止め |
| 出力安定化 | 大きなコンデンサ（C2: 47µF）を近接配置 |
| EN端子 | **メイン基板へのGPIO43(D6)制御ケーブル** |

### 注意事項

- TPS63802 も固定穴がないため、配線のみで宙吊りにしない
- 入出力端子に抜き差し力を集中させない
- **EN制御ケーブルの引っ張り対策を実施する**
- 熱放散を考慮した配置が望ましい（実装初期は熱計測なし）

## LiPo電池配置方針

| 項目 | 方針 |
|------|------|
| 固定方法 | 両面テープ + スポンジ（振動吸収） |
| 交換方式 | JSTコネクタ接続（着脱可能） |

## 初号機筐体の最終設計方針（実装前の確定事項）

### 基本方向

- ケース内にメイン基板(95×72)と電源基板(72×47)を独立して配置
- 端子台 + AWG28ケーブル(3～10cm)で接続（分離可能）
- 通信用USB（XIAO）と充電用USB（TP4056）をケース異なる側面に配置
- **RGB LED制御をMCP23017(I2C GPIO Expander)経由で実装**
- **Battery voltage monitor（分圧回路・GPIO4 ADC1_CH3）をメイン基板側に実装**
- **GPIO43(TPS63802 EN制御)とR_EN(100kΩ)配置確保**
- **microSD SPI配線時にCS=HIGH・SPI.end()処理対応**
- LiPo電池はJSTコネクタで着脱可能
- 初号機は「設計評価機」として、将来の分解・再製造前提

### 外部開口の確定順序

1. **必須開口**（デバイス着脱・制御）
   - microSD スロット
   - USB（通信・充電）×2
   - 端子台接続ケーブル通路
   - **RGB LED隙間（MCP23017経由制御）**

2. **センサ開口**（測定精度確保）
   - BME280 通気穴
   - LTR390 透明窓
   - Encoder 丸穴

3. **表示開口**（UI確認）
   - OLED 表示窓

### 筐体選定の進め方（後段）

1. メイン基板(95×72)・電源基板(72×47)のサイズを確認
2. 二基板を縦置き/横置きで配置試験
3. 開口位置・サイズの図面化
4. 既製品ケース（120mm×80mm×40mm程度）の候補選定
5. 加工試験（穴あけ・スリット）
6. 組立試験（基板固定・ケーブル接続・着脱確認）
