# 01_初期立ち上げ手順(01_BRINGUP_PLAN)

## 目的

本ドキュメントは、携帯型環境センサーロガー初号機の初期立ち上げ手順を整理するための作業計画書である。  
対象は、**Seeed Studio XIAO ESP32S3 Plus** を中心とした最小構成から開始し、段階的に各部品を追加しながら、配線・通信・電源・記録・表示・低消費電力動作を確認することである。

## 基本方針

- 最初から全機能を同時接続しない
- 最小構成で動作確認してから段階的に部品を追加する
- 通信確認と電源確認を分離して進める
- USB給電での検証を先行し、LiPo給電は後段で確認する
- 未確認事項は推測せず、実測または実機確認で確定する
- 不具合が出た場合に切り分けできるよう、追加部品は一度に1つずつとする
- 初号機は **ユニバーサル基板 + 既製モジュール** 前提とする
- 初号機では **USB通信用USB** と **LiPo充電用USB** を分離する

## MCU変更に伴う補足

本プロジェクトでは、当初想定していた ESP32-C3 SuperMini から XIAO ESP32S3 Plus へ MCU を変更した。  
これに伴い、初期立ち上げでは以下を優先した。

- まず XIAO ESP32S3 Plus 単体で書込み・起動・シリアル出力を確認する
- 次に I2C デバイスを 1:1 接続で個別確認する
- GPIO の最終確定は各部品の採否決定後に行う
- LiPo + 3.3V電源系の評価は USB給電での基本動作確認後に行う

## 立ち上げ対象の段階

### Phase 1: MCU単体確認
目的:
- XIAO ESP32S3 Plus 単体で書込み・起動・シリアル出力を確認する

確認項目:
- USB接続できること
- Arduino IDE から書込みできること
- シリアルモニタに動作メッセージを出せること
- 再書込みで異常が出ないこと
- Blink が動作すること

完了条件:
- シリアル出力の最小スケッチが安定動作する
- Blink が安定動作する

状態:
- **DONE**

---

### Phase 2: I2C最小構成確認
目的:
- XIAO ESP32S3 Plus と I2C デバイスの基本疎通を確認する

対象:

- OLED
- BME280
- DS3231

確認順:
1. XIAO ESP32S3 Plus + LTR390
2. XIAO ESP32S3 Plus + OLED

4. XIAO ESP32S3 Plus + DS3231
5. 4デバイス同時接続

完了条件:
- I2Cスキャナで各デバイスの認識が確認できる

- **DONE**

## 現時点の推奨実施順

1. 電源系単体試験結果を基準点として固定する
2. Battery voltage monitor 分圧回路を仮実装する
3. `vbat` 読出しスケッチでテスター値と比較する
4. `vbat` を CSV へ仮追加する
5. LiPo駆動での periodic logger / Deep Sleep logger を再確認する
6. 電源基板とメイン基板の二基板構成を具体化する
7. 筐体 / 最終レイアウトを詰める

## 注意事項

- 部品追加は一度に1つずつ行う
- 電源変更と通信変更を同時に行わない
- 未確認の端子機能は推測で接続しない
- LiPo接続前に極性をテスターで確認する
- 電源系は出力確認後にMCUへ接続する
- 問題発生時は最小構成へ戻して切り分ける
