## 基本方針

- 最初から全機能を同時接続しない
- 最小構成で動作確認してから段階的に部品を追加する
- 通信確認と電源確認を分離して進める
- USB給電での検証を先行し、LiPo給電は後段で確認する
- 未確認事項は推測せず、実測または実機確認で確定する
- 不具合が出た場合に切り分けできるよう、追加部品は一度に1つずつとする
- 初号機は **ユニバーサル基板 + 既製モジュール** 前提とする
- 初号機では **USB通信用USB** と **LiPo充電用USB** を分離する
- **電源基板とメイン基板は分離実装**し、4ライン端子台でケーブル接続する

## MCU変更に伴う補足

本プロジェクトでは、当初想定していた ESP32-C3 SuperMini から XIAO ESP32S3 Plus へ MCU を変更した。  
これに伴い、初期立ち上げでは以下を優先した。

- まず XIAO ESP32S3 Plus 単体で書込み・起動・シリアル出力を確認する
- 次に I2C デバイスを 1:1 接続で個別確認する
- GPIO の最終確定は各部品の採否決定後に行う
- LiPo + 3.3V電源系の評価は USB給電での基本動作確認後に行う

## 電源系変更に伴う補足（XC9306 → AE-TPS63802）

本プロジェクトでは、電源回路の XC9306 から **AE-TPS63802** へ変更した。  
これに伴い、以下が確定した。

- **EN端子付き** による Deep Sleep時電源遮断が可能
- **4ピン（VIN / GND / VOUT / EN）** による明確な入出力分離
- **端子台4ライン** （3.3V / GND / VBAT_SENSE_RAW / EN） を確定
- ハンダ作業温度を **280℃**（共晶ハンダ適正温度）に修正
- **電源基板別実装** の実装計画を確定

## 注意事項

### ハンダ作業時の注意

- ハンダ温度は **必ず 280℃** に設定する
- 320℃以上での加熱は不可
- AE-TPS63802 は 4ピン全てを確実に接続する
- C2 の極性（長足 → VOUT側）を確認する
- スズメッキ線を使用した「橋」配線で安定接触を図る

### 配線・接続時の注意

- 部品追加は一度に1つずつ行う
- 電源変更と通信変更を同時に行わない
- 未確認の端子機能は推測で接続しない
- LiPo接続前に極性をテスターで確認する
- 電源系は出力確認後にMCUへ接続する
- 問題発生時は最小構成へ戻して切り分ける

### 測定時の注意

- テスターは常にデジタル式を使用
- 無負荷での電圧確認を優先する
- 短絡テストは通電前に実施する
- 異常な発熱・異臭を見つけたら直ちに停止する
