# BME280廃止記録

## 状態

BME280は現行構成から外し、旧仕様として扱う。

---

## 廃止理由

BME280が破損していることが判明したため。  
以後、温湿度・気圧センサはBME680を現行採用品として扱う。

---

## 旧構成

| 項目 | 内容 |
|---|---|
| 旧センサ | BME280 |
| 測定対象 | 温度・湿度・気圧 |
| 通信 | I2C |
| 旧I2Cアドレス | 0x76として確認済み |
| 旧Chip ID | 0x60として確認済み |
| 状態 | 廃止 |

---

## 旧確認実績

BME280では過去に以下を確認済み。

- I2Cアドレス認識
- Chip ID確認
- キャリブレーションデータ読出し
- 生データ読出し
- 温度・湿度・気圧補正計算
- 連続測定
- RTC + microSD統合CSV保存
- Deep Sleep復帰後の再読出し

---

## 現行への影響

- BME280の確認実績は、BME680の確認実績として扱わない。
- BME680では、I2Cアドレス、ライブラリ、測定値、Deep Sleep復帰後動作を別途確認する。
- BME280向けコード、配線、注記は現行仕様へ流用する前に確認する。
