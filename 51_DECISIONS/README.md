# 50_DECISIONS

本ディレクトリは、設計判断と採用理由を保存するための領域です。

---

## 目的

- なぜその構成になったかを残す。
- 将来の再設計時の再発散を防ぐ。
- AI解析時の誤認識を減らす。
- 仕様変更と履歴を混同しないようにする。

---

## 運用ルール

- 1決定 = 1ファイルとする。
- ファイル名は `YYYY-MM-DD_内容.md` とする。
- 最新仕様を変更した場合は `CURRENT_STATUS.md` も更新する。
- 廃止された決定は削除せず、履歴として残す。
- 変更結果の時系列は `CHANGELOG.md` に記録する。

---

## 本ディレクトリに書く内容

- 採用理由
- 不採用理由
- 判断時点の前提
- 将来見直す条件

---

## 本ディレクトリに書かない内容

- 現行部品表
- 試験ログ
- 作業進捗
- 配線詳細
- 旧仕様本文
