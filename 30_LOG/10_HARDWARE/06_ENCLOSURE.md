# 06_ENCLOSURE

## 目的

本ファイルは、携帯型環境センサーロガー初号機の筐体（エンクロージャ）設計方針を整理するためのものである。  
初号機では完成度よりも **評価・改造・再配線のしやすさを優先** し、量産前提ではなく試作機前提の筐体とする。

---

## 初号機筐体の基本方針

初号機の筐体は以下の方針で設計する。

| 項番 | 方針 | 内容 |
|------|------|------|
| E-1 | 試作優先 | 分解・再配線・部品交換が容易な構造 |
| E-2 | 汎用ケース使用 | 既製品ケースを加工して使用 |
| E-3 | ネジ止め構造 | 接着固定は行わない |
| E-4 | 基板固定 | ユニバーサル基板をスペーサで固定 |
| E-5 | センサ開口 | 温湿度・気圧・照度・UV用に開口を設ける |
| E-6 | 充電口分離 | USB（通信）とUSB（充電）は別位置に配置 |
| E-7 | 電池交換可能 | LiPo電池は交換可能構造 |
| E-8 | 将来作り直し前提 | 初号機は「ケース設計評価機」と位置付ける |
| E-9 | 二基板構成 | メイン基板と電源基板を分離して配置する |

## ケース選定方針

ケースは以下の条件で選定する。

| 項番 | 条件 | 理由 |
|------|------|------|
| K-1 | ABS または ポリカーボネート | 加工しやすい |
| K-2 | ネジ止めタイプ | 分解可能 |
| K-3 | 基板固定用ボスあり | スペーサ固定可能 |
| K-4 | 外形 100mm 以下 | 携帯性確保 |
| K-5 | 厚さ 30mm 以下 | 携帯性確保 |
| K-6 | フタ加工可能 | OLED窓・Encoder穴加工 |
| K-7 | 側面加工可能 | USB・SDスロット開口 |
| K-8 | 二基板配置余地あり | メイン基板と電源基板を分離配置できる |

## 開口部設計方針

### 1. OLED表示窓

| 項目 | 内容 |
|------|------|
| 位置 | 上面 |
| 内容 | OLED表示窓 |
| 固定 | 内側からスペーサ固定 |
| 注意 | 表示窓はアクリル板で保護検討 |

### 2. Rotary Encoder

| 項目 | 内容 |
|------|------|
| 位置 | 上面または側面 |
| 穴 | 丸穴 |
| 固定 | ナット固定 |
| 機能 | 回転 + 押し込み |

### 3. センサ開口

| センサ | 開口方法 | 注意 |
|--------|----------|------|
| BME280 | 通気穴 | ケース内密閉禁止 |
| LTR390 | 透明窓 | UV/可視光透過必要 |
| DS3231 | 開口不要 | 温度影響少 |

### 4. USB

| 種類 | 用途 |
|------|------|
| USB（MCU） | 書込み・シリアル |
| USB（TP4056） | 充電 |

### 5. microSD

| 項目 | 内容 |
|------|------|
| 位置 | 側面 |
| 内容 | カード抜き差し可能 |

## 内部配置方針

ユニバーサル基板上の配置方針と、筐体内配置方針を一致させる。

| 位置 | 部品 |
|------|------|
| 上面 | OLED |
| 上面 | Rotary Encoder |
| 内部中央 | メイン基板 |
| 内部左 | センサ（I2C系） |
| 内部右 | microSD |
| 内部下 | 電源基板 |
| 下部 | LiPo電池 |

### 配置補足

- 電源基板は TP4056 の USB 口をケース外周に向けて配置する
- メイン基板と電源基板の間は、端子台と短いケーブルで接続する
- 電源基板の着脱や再配線がしやすい余裕を残す

---

## LiPo電池配置方針

| 項目 | 方針 |
|------|------|
| 固定 | 両面テープ + スポンジ |
| 交換 | JSTコネクタ接続 |
| 保護 | 金属部と絶縁 |
| 注意 | 発熱部品の近くに置かない |

---

## TP4056固定方針

| 項目 | 方針 |
|------|------|
| 主固定 | 絶縁両面テープで面固定 |
| 補助固定 | 配線保持または結束で引っ張り止め |
| USB荷重 | 筐体開口でも受ける |
| OUT± | 着脱点にしない |

補足:

- TP4056 は固定穴がないため、配線のみで宙吊りにしない
- 両面テープのみで荷重を受け切る前提にしない
- OUT± や JST 部に抜き差し力を集中させない

初号機筐体は以下を目的とする。

| 項番 | 評価項目 |
|------|----------|
| T-1 | サイズ感 |
| T-2 | 操作性 |
| T-3 | OLED視認性 |
| T-4 | USB位置 |
| T-5 | SDカード交換性 |
| T-6 | 電池交換性 |
| T-7 | センサ値のケース影響 |
| T-8 | 発熱 |
| T-9 | ノイズ |
| T-10 | 配線のしやすさ |
| T-11 | 電源基板とメイン基板の整備性 |
