# 03_電源デザイン(03_POWER_DESIGN)

## 電源構成

- LiPo 3.7V（容量は現時点で最終固定しない）
- TP4056系充電モジュール
- XC9306系 3.3V 昇降圧DC/DCコンバータ
- MCU / 各センサへ給電
- Battery voltage monitor 用分圧回路（後段実装）

## 現時点の電源候補

- XC9306系 3.3V 昇降圧DC/DCコンバータ
- 3.3V LDO
- TP4056系充電モジュール

※ 現時点では、LDO固定ではなく、昇降圧DC/DCも評価対象とする。  
※ 初号機では USB通信用USB と LiPo充電用USB を分離する。

## 初号機の電源基板方針

- 初号機では **電源系を別基板化** する
- 電源基板は **LiPo → TP4056 → XC9306** までを担当する
- メイン基板とは **3.3V / GND / VBAT_SENSE_RAW** を端子台で接続する
- LiPo ↔ TP4056 は JST コネクタを介して接続する
- 分圧回路は電源基板ではなく **メイン基板側** に置く

## 評価方針

1. まずは USB給電で評価用MCUとセンサの最小構成を確認する
2. 次に USB給電で最終構成候補MCUの単体動作を確認する
3. 次に XIAO ESP32S3 Plus 上でセンサ・表示・入力・RTC の基本動作を確認する
4. 次に XIAO ESP32S3 Plus 上で microSD を含む統合ロガーを確認する
5. 次に LiPo 単体、TP4056 単体、XC9306 単体を確認する
6. 次に LiPo → TP4056 → XC9306 → XIAO の順で接続する
7. 次に battery voltage monitor を追加する
8. 完成後に Deep Sleep時の消費電流を確認する

※ 電源系は、いきなり全体接続せず、段階的に確認する。  
※ 現時点で成立している統合結果は USB給電ベースであり、電池駆動結果とは分けて扱う。  
※ 完成まで電流測定は実施しない方針とし、消費電流評価は完成後に行う。  
※ 電池容量は運用途中で増減できる前提で扱い、1000mAh は初期評価用の暫定容量とする。

## MCU差分に関する方針

- 最終構成候補は XIAO ESP32S3 Plus とする
- 現在のセンサ・表示Bring-upは ESP32-WROOM系開発ボードでも実施している
- 電源評価では、評価用MCUと最終MCUの消費差を混在させない

## MCU変更による電流見積もり変更

ESP32-S3 系は ESP32-C3 系より動作電流・DeepSleep電流ともに大きい傾向がある。  
そのため電池駆動時間は当初想定より短くなる可能性がある。

対策:

- Wi-Fi / Bluetooth は常時OFF
- CPUクロックは必要に応じて下げる
- OLEDは常時消灯（操作時のみ点灯）
- 測定後すぐDeepSleepに入る
- UI確認用試験と最終低消費電力動作を分けて評価する

## TP4056 端子運用方針

- LiPo は **B+ / B-** に接続する
- 負荷側は **OUT+ / OUT-** を使用する
- XC9306 は **OUT+ → I**, **OUT- → G** とする
- TP4056 OUT± は本実装ではヘッダーピン着脱点にせず、短い配線で固定する
- TP4056 の USB 抜き差し荷重は、最終的に筐体側でも受ける前提とする

## 電源基板インターフェース

### 電源基板 → メイン基板

| 信号名 | 内容 |
|------|------|
| 3.3V | XC9306 出力 |
| GND | 共通GND |
| VBAT_SENSE_RAW | TP4056 OUT+ の生電圧 |

### バッテリ接続

| 接続 | 方針 |
|------|------|
| LiPo ↔ TP4056 | JSTコネクタ接続 |
| 電源基板 ↔ メイン基板 | 端子台接続 |

## Battery voltage monitor 方針

- 測定対象は **TP4056 OUT+ / OUT-** とする
- 分圧回路は **100kΩ / 100kΩ の 1:1** を第一候補とする
- 分圧回路はメイン基板側に置く
- ADC入力値が揺れる場合のみ **0.1uF の MLCC** を ADC入力-GND 間へ追加する
- コンデンサは **0.1uF / 10V以上 / X7R** を第一候補とする

## RTC時刻調整に関する電源運用方針

- 通常運用時に Wi-Fi で時刻同期しない
- PC 側でインターネット時刻同期済みの日時を USBシリアル経由で ESP32 に送る
- ESP32 は受信日時を DS3231 へ書き込む
- RTC調整時のみ USB 接続を前提とし、通常時は DS3231 を時刻源とする
- 試験時には `lostPower()` または不正時刻検出時の自動再設定版を併用する

## 充電系に関する現時点方針

- TP4056系モジュールは LiPo充電専用候補として扱う
- 初号機では充電中常時動作前提にせず、まず充電系と本体動作系を切り分ける
- 電池容量は固定仕様とせず、交換・増減しやすい実装を優先する
- 充電電流値、保護回路有無、負荷共有可否は未確認として扱う

- LiPo駆動での I2C / SPI / Deep Sleep を含む長時間統合安定性
- TP4056系の負荷共有可否
- TP4056系の実充電電流値
- DS3231 の主電源断後バックアップ保持最終判定
- Battery voltage monitor の本実装と校正

## 注意事項

- LiPo は極性確認後に接続する
- 3.3V 電源系は、出力電圧を単体確認してから MCU に接続する
- XC9306 の端子は、シルクの O / G / I 表記を基準に扱う
- TP4056 の負荷側は OUT± を使用する
- 電源方式の最終決定は機能完成を優先し、Deep Sleep時の消費電流評価は完成後に行う
- 評価用USB給電結果を、そのまま最終電池駆動結果とみなさない
